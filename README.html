供应链 Agent 工作台 v2.2.0-rag · Apache-2.0 开源版

本项目采用 Apache License 2.0 开源。当前实现边界与发布验证见 OPEN_SOURCE_RELEASE.md。

自带物料、交期、质量三个合成业务样例。基础工作台可独立运行；Agent 模式直接使用本机 deepseek-harness-sdk，并保留 Hermes 兼容适配。

python server.py --open
python doctor.py
python verify.py

.\.venv\Scripts\python.exe -m pip install -r requirements-dsh.txt
.\.venv\Scripts\python.exe server.py --open

默认 http://127.0.0.1:8765 。必要时 python server.py --host 0.0.0.0 --port 8765 --db /持久磁盘/workbench.sqlite3。存储默认 data/workbench.sqlite3，也可复制.env.example为.env并设置WORKBENCH_DB；启动参数优先。

左侧切场景；右侧公共导航切目标、数据、Case、规则、证据等，旁边是 Agent。浏览器刷新只恢复观察，不重新提交任务。

代码含 app/data_workspace.py、web/data-workspace.js/css、72 个 HTTP 接口统一注册与 API 测试。rules-view显示当时实际配置和登记的规则原文，而不是新的AI摘要。完整追溯以显式_source_refs为准，没有记录的Python内部中间结果不猜测。

doctor.py 检查 Python、真实 SQLite、API 导出和可选 DSH SDK，不调用模型。verify_dsh.py --live 才会显式调用一次当前配置的真实模型。

详见 docs/数据工作区与数据版本.md、docs/API合同与验收分层.md。本模板为已提供样例的可运行基座，不宣称已验证未提供的企业正式规则，也没有真实发送邮件或飞书消息。

business-v1.2 仅作为旧场景兼容 ID 保留，不表示运行时依赖旧 ZIP 或外部生成平台。

本地 DSH 进程、配置、批准、重启边界和验证命令见 docs/DSH本地SDK接入.md。没有实际模型地址与密钥时，不声明真实模型、MCP 或飞书已联调。定时飞书图片由外部 DSH 任务与飞书 CLI Skill 拉取；工作台提供 scheduled-feishu-cli-v1 脱敏批次接收合同，不实时生成图片。
